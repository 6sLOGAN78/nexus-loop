# Nexus Loop UI review

## Before

- `before/operator-desktop.png` — one dense three-pane desk; the gate and report provenance were strong, but every layer competed at once.
- `before/operator-mobile.png` — stacked internal scroll panels clipped the claim, evidence, and controls into separate fragments.

## Iterations

- `cycle-1/` — introduced landing, dashboard, and case-file routes. The mobile timeline opened on empty early days and the dashboard delayed its findings.
- `cycle-2/` — opened the narrow timeline on fault windows, moved regression cards above the dashboard timeline, and tightened the mobile action.
- `cycle-3/` — restored signed-copy keyboard and reload compatibility without changing the visible hierarchy.
- `cycle-4/` — removed a duplicated impact number, made the timeline count report-driven, and added console/network/overflow checks. This is the selected final set.

Each cycle contains landing, dashboard, and detail captures at 1440×900 and 390×844.
