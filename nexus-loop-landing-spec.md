# Landing Page Specification: Yellow.ai Nexus Loop & Operator Desk

## 1. Executive Summary
This document provides a comprehensive design, structure, and content specification for the landing page of the **Yellow.ai Nexus Loop**. The Nexus Loop is an automated evaluation pipeline and human-in-the-loop operator desk for conversational AI.

**Target Audience:** QA Engineers, AI Product Managers, and Conversational Designers.
**Core Value Proposition:** Stop guessing if your AI works. Automate the evaluation (deterministically, without LLMs), verify fixes via a replay service, and let human managers make data-backed decisions with the Operator Desk.

---

## 2. Visual Design & UI Guidelines

### Color Palette (from `nexus_loop/static`)
*   **Sunken Canvas (Background):** `#F7F8F9` (Light gray for the main canvas layout).
*   **Surface Cards:** `#FFFFFF` (White cards with soft borders, giving a raised effect).
*   **Primary Text (Chrome & UI):** `#232326` (Dark Charcoal) / `#172b4d`.
*   **Success / Accept:** `#1F845A` (Traffic light green used for the "Accept" gate).
*   **Danger / Reject:** `#C9372C` (Traffic light red used for "Reject" and "Needs Attention" mode).
*   **Warning:** `#E5A000` (Used for KPI cost warnings).
*   **Neutral / Defer:** `#8C9BAB` (Used for "Defer" gate).

### Typography
The product specifically uses exactly two font families:
*   **Headlines & Technical Terms:** `Newsreader` (Serif). Used for claims, span headings, and technical jargon (e.g., owner paths, code).
*   **UI Chrome & KPIs:** `Source Sans 3` (Sans-serif). Used for buttons, badges, navigation, and numbers.
*   **Fallbacks:** `Iowan Old Style`, `Palatino`, `Segoe UI`.

### Aesthetics & Components
*   **Layout:** Raised, rounded cards (`border-radius: 8px`) on a sunken canvas. 
*   **Data-heavy but clean:** Show charts, before-and-after pair-bars, and 5-column KPI impact strips.
*   **Gates:** Traffic-light visual patterns (Green, Red, Grey) for actions.

## 3. Section-by-Section Content

### Section 1: Hero (Above the Fold)
**Headline (H1 - Newsreader):** Evaluate. Verify. Decide.
**Subheadline (Source Sans 3):** The Yellow.ai Nexus Loop is a deterministic evaluation pipeline and human-in-the-loop Operator Desk. Run thousands of checks, verify against golden sets, and empower managers with tracing data.
**Primary CTA:** View the Demo (Green `#1F845A`)
**Secondary CTA:** Read the Documentation (Ghost / Neutral)
**Visual Mockup:** A high-fidelity, split-screen mockup. Left side: The terminal running `python3 run.py --kit kit --team demo`. Right side: The Operator Desk showing a "Needs Attention" finding with the green and red traffic light gates.

### Section 2: Core Pipeline (How it Works)
**Layout:** 3-step vertical timeline or alternating feature blocks.
**Headline:** A deterministic, LLM-free evaluation pipeline.
*   **Step 1: Cold Run.** `run.py` evaluates agent logic, folds facts, and finds coverage gaps across thousands of logs.
*   **Step 2: Replay.** The replay service verifies proposed fixes against ground truth and generates before/after impact bars.
*   **Step 3: The Operator Desk.** Human managers review organized panes: "Needs Attention", "Dismissed Signals", and "No Measurement".

### Section 3: The Operator Desk Features (Bento Box)
**Layout:** Modern Bento Box grid with cards of varying sizes.
*   **Card 1 (Psychology-first UI):** No ambiguous buttons. A strict "Accept, Reject, Defer" gate that forces reasoned decisions and writes back to `prescriptions[].approval` atomically.
*   **Card 2 (Manager English):** Complex technical jargon (e.g., "fallback_triggered") is automatically translated into clear "Manager English" for non-technical approvers.
*   **Card 3 (Signed Copy):** One click generates a fixed, plain-text hand-off note, ensuring no context is lost when escalating decisions to engineering.
*   **Card 4 (Impact KPIs):** See the exact impact of a fix. Cost warnings, resolution rates, and abandoned metrics generated by the pipeline are front and center.

### Section 4: Metrics & Scale
**Visual:** A dashboard strip showing mock KPIs from the `nexus_loop/report.py` logic.
**Content:** 
*   *Scale:* Processes 100x datasets seamlessly.
*   *Precision:* 100% deterministic, no hallucination in root-cause diagnosis.
*   *Auditability:* Every decision generates an immutable `decisions.log`.

### Section 5: CTA / Footer
**Headline:** Ready to secure your AI deployments?
**Subheadline:** Explore the repository to run the cold pipeline and spin up the Operator Desk locally.
**CTA Button:** Explore the GitHub Repository
**Footer Links:** Solution Overview | UX Psychology | API Contract | Signed Copy PRD

## 4. Implementation Recommendations
1. **Framework:** Next.js (App Router) with Tailwind CSS.
2. **Fonts:** Use `next/font/google` to import `Newsreader` and `Source_Sans_3`.
3. **Animations:** Subtle Framer Motion fade-ins for the operator desk mockups. Focus on clean, snappy interactions matching the real UI's lightweight JavaScript.
